# Photography slots

Drop a photo into this folder using the **exact filename** below and it appears on the site automatically. Until then the site shows the art-directed placeholder and its `Image · …` label. Use JPG, about 2400px on the long edge, under 500 KB, colour graded cool and natural.

In Figma these are **image fills** on the matching frames. In Wix Studio, upload them to the Media Manager and set them as the image or section background.
